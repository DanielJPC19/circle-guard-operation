Arquitectura General

Módulos Terraform — Reutilizables y Separados

  • aks/ — Azure Kubernetes Service (cluster K8s + node pools + logging)
  • acr/ — Azure Container Registry (almacenamiento de imágenes)
  • k8s-addons/ — Helm charts (cert-manager, Prometheus, Grafana, sealed-secrets, KEDA)

Backend remoto: Azure Blob Storage (cgtfstate) — estado compartido entre dev/staging/prod

Estructura de Módulos — Archivos Clave

infra/modules/
├── aks/
│   ├── main.tf          (azurerm_kubernetes_cluster)
│   ├── variables.tf     (cluster_name, node_count, vm_size)
│   └── outputs.tf       (kube_config, cluster_id)
├── acr/
│   ├── main.tf          (azurerm_container_registry)
│   └── variables.tf     (registry_name, sku)
└── k8s-addons/
    ├── main.tf          (helm_release para cert-manager, Prometheus, etc)
    └── variables.tf     (enable_monitoring, enable_istio)

4. CI/CD — Pipelines Automatizados

✅ COMPLETO
  • ✅ SonarQube, Trivy, OWASP ZAP
  • ✅ GitHub Actions + Jenkins — dev → staging → prod
  • ✅ Aprobación manual para producción

CI/CD Pipeline Flow

GitHub Actions: CI Develop (Rama develop)

  • Trigger: Push a rama develop
  • Build: ./gradlew bootJar --parallel
  • Unit Tests: ./gradlew unitTest (mínimo 70% cobertura)
  • Security Scanning: Trivy (escaneo vulnerabilidades Docker)
  • Code Quality: SonarQube (análisis estático)
  • Registry: Push imagen `:dev-{SHA}` a ACR

SonarQube Quality Analysis

Detecta:

  • Code smells (duplicaciones, complejidad ciclomática)
  • Vulnerabilidades de seguridad (OWASP Top 10)
  • Bug hotspots
  • Coverage de tests

Quality Gate: Bloquea merge si coverage < 70% o hay issues críticas

GitHub Actions: CI Main (OWASP ZAP)

circle-guard-development/.github/workflows/ci-main.yml
  security-dast:
    name: OWASP ZAP Dynamic Testing
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker run -t owasp/zap2docker-stable \
          zap-baseline.py -t http://gateway:8087 \
          -r zap-report.html || true
      - name: Upload ZAP Report
        uses: actions/upload-artifact@v4
        with:
          name: zap-report
          path: zap-report.html

Jenkins CD: Deploy a Staging (AKS)

  • Trigger: GitHub Actions entrega IMAGE_TAG (ej: staging-a3f9c12)
  • Auth Azure: az login con service principal
  • Kubectl Config: az aks get-credentials para circleguard-stage
  • Deploy: kubectl apply -f k8s/services/stage/ (todos los 8 servicios)
  • Database: Reset Postgres + Flyway migrations
  • Health Checks: 24 reintentos × 15s (360s timeout) al endpoint /actuator/health
  • Slack Notify: Notificación de éxito o fallo

REGLA: Conventional Commits → SemVer automático

feat:  → versión MENOR (v1.0.0 → v1.1.0)
fix:   → versión PARCHE (v1.0.0 → v1.0.1)
BREAKING CHANGE: → versión MAYOR (v1.0.0 → v2.0.0)

EJEMPLOS:
  feat(auth): add LDAP password reset (US-01)
  fix(kubernetes): add RBAC roles (US-11)
  chore(ci): upgrade SonarQube version

Plan de Rollback (5 pasos)

  • 1. Detener: requerir aprobación manual en Jenkins
  • 2. Revertir imagen: scripts/update-image-tag.sh <service> <old-tag>
  • 3. Revertir manifests: kubectl rollout undo deployment/<svc>
  • 4. Revertir infra: git revert + terraform apply (si aplica)
  • 5. Verificar: health checks + métricas Grafana
